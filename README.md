# Shravya U Shetty — Portfolio Website

Professional portfolio highlighting five academic and software projects: ASSA Event Management, Placement Week Scheduler, Resume Skill Gap Analyzer, Intelligent Multi-Cabin Access, and Underwater Object Detection.

**Website:** https://ShravyaUShetty24.github.io/ (after GitHub Pages is enabled).

## Publishing
GitHub repository **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.

## Project links
All cards link to the five separate repositories. Three repositories contain application code; the remaining two are academic documentation/case studies. The resume analyzer repository is a simplified public edition.

## Editing
Modify `index.html` for project details and `styles.css` for the layout. No framework or build step required. The site is static and can be served from GitHub Pages.

## Accuracy
No demo application is claimed to be live. Project performance figures, academic project contributions, and deployment status should be verified before adding new claims.
